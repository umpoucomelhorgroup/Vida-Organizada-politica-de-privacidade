Política de Privacidade

Aplicativo Vida Organizada — WPrimeApps

Última atualização: 7 de outubro de 2026

1. Responsável pelo aplicativo

O aplicativo Vida Organizada é desenvolvido e disponibilizado pela WPrimeApps.

Para questões relacionadas à privacidade ou ao tratamento de informações, entre em contato pelo endereço de e-mail informado ao final desta política.

2. Quais dados o aplicativo coleta

O aplicativo Vida Organizada não coleta, transmite ou armazena em servidores controlados pelo desenvolvedor os dados inseridos pelo usuário.

As informações inseridas pelo usuário, incluindo, entre outras:

  • tarefas;
  • hábitos;
  • anotações;
  • receitas;
  • despesas;
  • leituras;
  • projetos;
  • planos de estudos;
  • diários;
  • coisas que quero fazer;
  • afirmações;
  • metas.

são armazenadas localmente no dispositivo do usuário para permitir o funcionamento das funcionalidades do aplicativo.

O desenvolvedor não possui acesso direto a essas informações armazenadas localmente no dispositivo.

3. Onde os dados ficam armazenados

Os dados criados pelo usuário são armazenados localmente no dispositivo, utilizando o armazenamento privado do aplicativo e seu banco de dados local.

Essas informações permanecem no dispositivo enquanto não forem excluídas pelo usuário ou removidas como consequência da desinstalação ou limpeza dos dados do aplicativo.

4. Compartilhamento de dados

O desenvolvedor não vende, aluga, compartilha ou fornece a terceiros os dados inseridos pelo usuário no aplicativo.

Como os dados são armazenados localmente no dispositivo e não são enviados aos servidores do desenvolvedor, o desenvolvedor não possui acesso a esses dados.

5. Conexão com a internet

O aplicativo não requer conexão com a internet para suas funcionalidades principais.

Os dados criados pelo usuário não são transmitidos para servidores externos controlados pelo desenvolvedor.

Caso funcionalidades futuras que dependam de conexão com a internet sejam adicionadas ao aplicativo, esta Política de Privacidade poderá ser atualizada para refletir essas alterações.

6. Backup e exportação

O aplicativo pode permitir que o usuário realize o backup ou a exportação de seus dados por meio de um arquivo JSON.

O arquivo de backup é salvo no dispositivo ou em outro local escolhido pelo próprio usuário. O usuário é responsável pelo armazenamento, segurança e eventual compartilhamento desse arquivo.

O desenvolvedor não recebe automaticamente os arquivos de backup criados pelo usuário.

7. Exclusão dos dados

O usuário pode excluir os dados armazenados localmente por meio das funcionalidades de exclusão disponíveis no aplicativo.

Também é possível remover os dados do aplicativo por meio das configurações do dispositivo Android, quando aplicável.

A desinstalação do aplicativo também pode resultar na remoção dos dados armazenados localmente pelo aplicativo, conforme o funcionamento do sistema Android.

8. Segurança

Os dados do usuário são armazenados localmente no armazenamento privado do aplicativo.

O desenvolvedor adota medidas razoáveis para proteger o aplicativo e seus dados contra acesso não autorizado. No entanto, nenhum método de armazenamento ou dispositivo eletrônico pode ser considerado absolutamente seguro.

O usuário também é responsável pela segurança de seu próprio dispositivo e de eventuais arquivos de backup exportados.

9. Permissões do aplicativo

O aplicativo pode solicitar determinadas permissões do sistema Android para disponibilizar algumas de suas funcionalidades:

  • Notificações: utilizada para enviar lembretes e notificações relacionados às funcionalidades configuradas pelo usuário.
  • Armazenamento: utilizada, quando necessária, para permitir a criação, exportação ou importação de arquivos, como backups.
  • Vibração: utilizada para fornecer alertas por vibração em notificações, temporizadores e outras funcionalidades.

O aplicativo solicita apenas as permissões necessárias para suas funcionalidades. As permissões podem ser concedidas, negadas ou, quando permitido pelo sistema Android, revogadas pelo usuário por meio das configurações do dispositivo.

10. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir alterações no aplicativo, em suas funcionalidades ou nos requisitos legais aplicáveis.

Quando apropriado, alterações relevantes poderão ser informadas por meio do aplicativo ou de sua página de distribuição.

Recomenda-se que o usuário consulte esta Política de Privacidade periodicamente para verificar eventuais alterações.
